**NexCart — AI-Enhanced E-Commerce Platform**

NexCart is a full-stack e-commerce web application that combines modern shopping features with real AI capabilities. Users can browse products, manage cart and wishlist, and complete a checkout flow, while admins can dynamically manage products and generate AI-powered product descriptions.

The platform integrates Groq’s LLaMA 3.1 model via a secure Express backend to generate intelligent product descriptions in real time. It also includes features like filtering, sorting, ratings, reviews, and persistent state management using React Context API and localStorage.

**🛠 Tech Stack**
Frontend: React, React Router, Context API
Backend: Node.js, Express
AI Integration: Groq API (LLaMA 3.1)
State Management: Context API + localStorage
Deployment: Vercel (Frontend), Render (Backend)
